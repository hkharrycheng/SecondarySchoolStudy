# SecondarySchoolStudy — 升中分析

升中分析工具（J10）：Band 1 中學地圖、AI 評價、升中流程時間線。

## 功能

- **中學地圖**：香港 18 區地圖顯示所有 Band 1 中學（按 Band 分組配色），可按教學語言、Band、關鍵字搜尋過濾；點擊區域顯示該區中學清單；點擊學校顯示 AI 評價、官網、JUPAS 大學%、本地大學升讀%
- **升中流程**：Cici（2029 升中）與 Coco（2031 升中）兩條 Path 並排，相應階段水平對齊，時間由上至下由近至遠

## 數據源

- 飛書多維表格：https://feishu.doubao.com/base/G7tZbbEmYaSsAmstU6gcullHn8Z
